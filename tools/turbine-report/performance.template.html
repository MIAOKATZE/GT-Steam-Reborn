如何读这些数值

“效率上限”是机器的发电倍率上限；“节汽率”作用于输入量，两者独立。表内“输出 EU/t”按生产代码先以 Java float → long 取得基础输出，再以 long × 效率 / 10000 结算。耗汽也保留 Java 浮点中间值与向零取整，未套用显示用的 int 上限。

这是一张稳态对照表。实际运行还有效率爬升、基础输出平滑、每 tick 全额供汽检查，以及发电仓与冷却产物出口的约束。

材料与芯片的边界

三档材料统一替换壳 / 管 / 齿轮；第三档齿轮位使用装配线方块。电压档固定使用 256 块标准机械方块，与材料档分开。

循环超限芯片只在额外组 k = 4 时生效；普通蒸汽的输出倍率保持不变，过热 / 超临界在同一蒸汽家族内叠加。配套 EU/L 分母同步变化；实际取整值以 Java 采样为准。LuV（Tier 6）起解锁致密蒸汽及超临界蒸汽。

配方电压与并行

配方电压上限取 min(机械方块档, 内置机器档 + 增压档)。玻璃等级必须不低于机械方块档；表格假定结构与玻璃满足要求。

并行上限为 1 + 2 × 内置机器档 + 内置机器数量；真正同时运行的配方数量仍受材料、能源与输入输出条件限制。
